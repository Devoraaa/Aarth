# AARTH — The Archival Record

An artisanal luxury fashion storefront built with **React**, **TypeScript**, and **Vite**, ready for headless Shopify integration.

## ✨ Features
- **Heirloom Aesthetic**: Antique textured parchment backgrounds, classic serif typography, and zero-border-radius design.
- **Responsive Architecture**: High-fashion responsive lookbook layouts across Mobile, Tablet, and Desktop with bespoke mobile photoshoot integration.
- **Coming Soon / Atelier Preview**: Interactive countdown & password-protected early access gateway with responsive desktop (16:9) & mobile (9:16) stepwell visuals.
- **Curated Archive**: Grid showcase for limited handloom pitloom silk silhouettes and botanical dyes.
- **Headless Ready**: Clean React + TypeScript component model built for easy connection to Shopify Storefront API.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠 Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Animations & Icons**: Framer Motion, Lucide React
